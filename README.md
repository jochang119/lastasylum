# Last Asylum 좌표 조회 툴

서버 번호 + 닉네임으로 플레이어 좌표만 간단하게 조회하는 웹앱입니다.

## 현재 방식

API 키가 코드에 직접 들어가 있습니다.  
**보안상 권장하지 않는 방식**이므로, 테스트 후 키를 새로 발급받고 환경변수 방식으로 바꾸는 것을 추천합니다.

## 배포 방법 (Vercel)

1. 이 폴더를 GitHub에 올립니다.
2. Vercel에서 해당 저장소를 Import 합니다.
3. Deploy 버튼을 누릅니다. (환경변수 설정 필요 없음)

배포가 끝나면 바로 사용할 수 있습니다.

## 주의사항

- 현재 API 키가 코드에 노출되어 있습니다.
- GitHub 저장소가 Public이면 키가 공개됩니다. Private 저장소를 권장합니다.
- 키가 유출된 상태이므로, 나중에 반드시 키를 폐기하고 새로 발급받으세요.
