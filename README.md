# Last Asylum 좌표 조회 툴

서버 번호 + 닉네임으로 **항상 최신 좌표**만 간단하게 조회하는 웹앱입니다.

## 특징

- `?fresh=1` + 캐시 완전 차단으로 조회할 때마다 게임에서 새로 가져옴
- API 키를 코드에 직접 넣음 (환경변수 불필요)
- 좌표만 크고 깔끔하게 표시

## 무료 배포 (Vercel)

1. 이 폴더를 GitHub 저장소에 올립니다. (Private 권장)
2. [Vercel](https://vercel.com) 가입 후 **Import Project**
3. 해당 저장소 선택 → Deploy

환경변수 설정 없이 바로 배포됩니다.

배포 후 주소에서 바로 사용 가능합니다.

## 주의

- API 키가 코드에 포함되어 있습니다.
- Public 저장소로 올리면 키가 노출됩니다. Private 권장.
- 키가 유출되면 Last Asylum Tracker 사이트에서 폐기 후 새로 발급하세요.
